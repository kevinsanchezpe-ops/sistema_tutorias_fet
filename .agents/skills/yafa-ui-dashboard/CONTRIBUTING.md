# Contributing

Contributions that make Yafa-UI: Dashboard clearer, more portable, or more useful across coding agents are welcome.

## Before opening a pull request

1. Keep `SKILL.md` concise and route substantial conditional guidance into `references/`.
2. Preserve the machine identifier `yafa-ui-dashboard` and the display name `Yafa-UI: Dashboard`.
3. Keep examples framework-neutral unless a framework-specific detail materially improves the instruction.
4. Use named Lucide icons for interface examples and code-native assets for repository artwork.
5. Do not add generated dashboard screenshots, private product paths, secrets, telemetry, executable hooks, or runtime dependencies.
6. Validate the skill frontmatter and every relative Markdown link.
7. When changing visual rules, verify the example at 320px, 390px, 768px, 1024px, and 1440px where applicable.

Explain the user-facing reason for the change and include before/after evidence for visual behavior.
